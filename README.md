## Описание

Backend-часть интернет-магазина, разработанная на Django. Проект реализует полный цикл работы интернет-магазина: каталог товаров, корзина, оформление заказов и личный кабинет пользователя.

## Функционал

- Каталог товаров с категориями
- Карточки товаров с детальной информацией
- Корзина покупок с проверкой остатков на складе
- Оформление заказов с валидацией данных
- Личный кабинет с историей заказов и статусами
- Админ-панель для управления товарами, заказами и пользователями
- Команды для импорта/экспорта данных товаров

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте: `source venv/bin/activate` (macOS/Linux) или `venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Создайте файл `.env` на основе `.env.example`
6. Настройте PostgreSQL базу данных
7. Примените миграции: `python manage.py migrate`
8. Создайте суперпользователя: `python manage.py createsuperuser`
9. Запустите сервер: `python manage.py runserver`
